## What is in this repository

Each enhancement folder contains two subfolders: original_code holds the files as they were before my changes, and new_code holds the enhanced versions.

**Enhancement 1, Software Design and Engineering (Travlr Getaways, CS 465):** Added a DELETE endpoint for trips, fixed a bug in the JWT authentication middleware, and introduced centralized error handling. [View files](Enhancement1/)

**Enhancement 2, Algorithms and Data Structures (Appointment service, CS 320):** Added a date-indexed TreeMap to AppointmentService for O(log n + k) range queries, verified with JUnit tests. [View files](Enhancement2/)

**Enhancement 3, Databases (Travlr Getaways, CS 465):** Added schema validation, a unique trip code constraint, input sanitization, an environment variable based MongoDB connection, and pagination. [View files](Enhancement3/)
